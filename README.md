# Контур Комфорта — сайт

Многостраничный сайт на базе дизайн-макетов Stitch.

## Запуск

Откройте `index.html` в браузере или поднимите локальный сервер из корня проекта:

```bash
python -m http.server 8765
```

Затем перейдите на http://localhost:8765

## Страницы

| Файл | Раздел |
|------|--------|
| `index.html` | Главная |
| `doma.html` | Строительство домов |
| `bani.html` | Бани |
| `okna.html` | Окна ПВХ |
| `alyuminij.html` | Алюминиевые конструкции |
